Actualizaciones oficiales de GREÑA Live PRO

Solo tú decides cuándo avisar. Guardar un borrador NO envía ninguna notificación. Los usuarios únicamente verán una actualización cuando pulses «Publicar oficialmente» y el instalador esté verificado en GitHub Releases.

Seguridad: la publicación solo se permite cuando GitHub Releases contiene una versión estable con latest.yml y su instalador Windows. Preparar una compilación nunca activa notificaciones por sí solo.

Activar o renovar por usuario · sin códigos

Escribe el GREÑA ID de la persona, elige los días y GREÑA los activa directamente. Si ya tiene una licencia vigente, se suman al tiempo que le queda; si no, el plazo comienza ahora. El usuario debe haberse registrado en Cloudflare.

BETA ofrece acceso indefinido mientras no revoques la licencia o suspendas la cuenta. El primer inicio de sesión vincula la licencia al equipo. Los días de las licencias normales se cuentan aunque la app esté cerrada.

Generar códigos de activación

La duración elegida se guarda dentro de cada licencia. El plazo empieza en la primera activación; si se renueva antes del vencimiento, los nuevos días se suman al tiempo restante. Copia los códigos antes de cerrar esta sección.
